# Lessons

- Never put a literal credvault secret token (double-brace `SECRET:KEY` form) inside a Bash heredoc, e.g. when writing docs: the credvault PreToolUse hook resolves it and fails the whole command if the key is missing. Use the Write tool for files that must contain that string.
- vue-tsc 3.3.x does not support TypeScript 7; pin typescript@5.x in Vue projects until vue-tsc catches up.
- gofmt realigns struct field columns; exact-string Python replaces on struct literals silently miss. Use regex with `\s+` (or `re.sub` on the field name) when patching Go structs.
- The SHE BASH git-guard blocks a Bash command that contains `git commit` while the current branch is `main`, even if the same command does `git switch -c` first (seen with a `release/...` name). Run the branch switch as its own command, then commit.
- gridstack `GridStack.init` adopts existing `.grid-stack-item` children as 1x1 auto-positioned nodes (`auto: true` default); explicit `makeWidget` placement then shoves those placeholders around and they shove real boxes back (each box ended one own-height lower after a remount). Init with `auto: false` and place every child yourself. Also register `mounted` ids synchronously, or a remount renders a ghost for every box and places each id twice.
- electron-builder mac builds with no identity keep Electron's linker-only signature and no resource seal; a quarantined download then fails Gatekeeper as "damaged" (not merely unidentified). Ad-hoc sign in an afterSign hook (`codesign --force --deep --sign -`) so users only see the right-click → Open prompt; real fix is a Developer ID identity.
